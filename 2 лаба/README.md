# Лабораторная работа № 2. Групповой чат со встроенной базой данных

## Цель

Расширить групповой чат из первой лабораторной работы постоянным хранилищем,
которое не теряет данные после штатного или аварийного завершения программы.

## Реализация

Основная реализация `PersistentGroupChat` использует встроенную файловую СУБД
H2. Отдельный сервер и сетевое подключение не требуются. В базе сохраняются:

- имя, сетевой статус, время последнего подключения и настройка уведомлений каждого пользователя;
- полная история сообщений;
- очереди доставленных, но ещё не прочитанных сообщений.

Каждая публичная операция чата выполняется как отдельная транзакция. После
успешного изменения транзакция немедленно фиксируется на диске. При ошибке
операция полностью откатывается. Это не позволяет оставить связанные таблицы в
частично обновлённом состоянии.

Интерфейс `GroupChat`, модели и тесты первой лабораторной сохранены. Старая
реализация `InMemoryGroupChat` оставлена для регрессионной проверки, а консольная
программа второй лабораторной использует `PersistentGroupChat`.

## Таблицы базы данных

| Таблица | Назначение |
|---|---|
| `users` | Состояния и настройки пользователей |
| `messages` | История всех сообщений |
| `deliveries` | Непрочитанные сообщения конкретных пользователей |

```text
src/main/java/ru/study/chat/
├── GroupChat.java               — пользовательский интерфейс

├── InMemoryGroupChatTest.java   — тесты из лабораторной № 1

```

## Автоматическая проверка

Требуются Java 17 или новее и Maven 3.9 или новее.

```shell
mvn test
```

Тесты второй лабораторной проверяют:

- основной сценарий группового чата через БД;
- сохранение всего состояния после штатного закрытия и повторного запуска;
- восстановление зафиксированных данных после команды H2 `SHUTDOWN IMMEDIATELY`,
  имитирующей аварийное завершение процесса;
- отсутствие потерь при одновременной отправке сообщений из нескольких потоков.

## Ручной запуск

```shell
mvn package
java -jar target/persistent-group-chat-1.0-SNAPSHOT.jar
```

По умолчанию база создаётся в `data/group-chat.mv.db`. После выхода запустите JAR
повторно: пользователи, состояния, история и непрочитанные сообщения останутся.

Другой путь к файлу базы можно передать первым аргументом:

```shell
java -jar target/persistent-group-chat-1.0-SNAPSHOT.jar ./my-data/chat
```

Для ручной проверки аварийного завершения остановите приложение во время работы
комбинацией `Ctrl+C`, затем запустите его снова и просмотрите историю и состояния.
